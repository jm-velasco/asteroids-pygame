# Asteroids

A clone of the classic Asteroids game, built with Python, Pygame and object-oriented programming. Guided project from the Boot.dev Python course.

## Features

- Game loop running at 60 frames per second
- Player ship with rotation, thrust and shooting
- Asteroids that split into smaller ones when shot

## Requirements

- Python 3.13 or newer
- [uv](https://docs.astral.sh/uv/)

## Setup

```bash
git clone <repo-url>
cd asteroids
uv sync
```

## Run

```bash
uv run main.py
```

## Controls

| Key     | Action             |
| ------- | ------------------ |
| `A`     | Rotate left        |
| `D`     | Rotate right       |
| `W`     | Move forward       |
| `S`     | Move backward      |
| `Space` | Shoot              |
