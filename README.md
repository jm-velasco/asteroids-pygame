# Asteroids
 
A clone of the classic Asteroids game, built with Python, Pygame and object-oriented programming. Guided project from the Boot.dev Python course.
 
## What it covers
 
- Setting up and installing Pygame
- A game loop that renders at 60 frames per second
- A `Player` class with movement and user input
- Asteroids the player has to avoid
- Game objects and their interactions modelled as classes
## Requirements
 
- Python 3.10 or newer
- [Pygame](https://www.pygame.org/)
